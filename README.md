# TheDivision2keybindchanger
This is a The Division 2 keybind remapper for linux which allows you to remap the keyboard keys Ubisoft doesn't allow you to remap. It's been coded with the help of Claude and is a Python application.

As I no longer play on Windows I have no interest in making a Windows version. Anyone who wants to may fork this build and adjust it for Windows is they so desire. As long as I am credited as the original creator.
